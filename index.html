Case Study: AI Playwright GenAI

Problem: Hand-writing and maintaining Playwright scripts for every new scenario slows down regression coverage as a product grows.

Approach: Built an open-source tool that takes a plain-English scenario ("As a user, I want to log in with valid credentials") and uses Google Gemini to generate a runnable TypeScript Playwright test, including selectors, navigation, and assertions.

Result: New scenarios go from spec to a running test in minutes instead of hand-writing boilerplate. (Swap in a real before/after time or defect metric here once you've measured one on a live suite.)
